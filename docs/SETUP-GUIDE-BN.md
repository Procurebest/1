# ProcureBest — GitHub + Cloudflare দিয়ে ফ্রিতে চালানোর গাইড

এই গাইড অনুসরণ করলে কোনো কোড না লিখেই সাইটটি অনলাইনে চালু হবে। সময় লাগবে প্রায় ১–২ ঘণ্টা।
প্রথমে সাইট চলবে Cloudflare-এর ফ্রি ঠিকানায় (যেমন `procurebest.আপনার-নাম.workers.dev`)।
সব ঠিক থাকলে পরে ডোমেইন কিনে যুক্ত করবেন (ধাপ ১২)।

**চিহ্ন:** 🖱️ = ওয়েবসাইটে ক্লিক করে করার কাজ · ✏️ = কিছু লিখে বা পেস্ট করে করার কাজ

---

## ১. ফোল্ডারে কী আছে

| জিনিস | কী কাজ |
|---|---|
| `src/` | সাইটের "মস্তিষ্ক" — পাতা, অ্যাডমিন প্যানেল, পরীক্ষা, অর্ডার |
| `public/` | ডিজাইন (CSS), ক্যালকুলেটরের কোড, লোগো ও ছবি |
| `wrangler.jsonc` | Cloudflare-এর সেটিংস ফাইল — এখানে দুটি আইডি বসাতে হবে (ধাপ ৫) |
| `docs/` | এই গাইড |
| `dev/` | ডেভেলপারদের জন্য লোকাল টেস্ট (আপনার দরকার নেই) |

প্রাথমিক কনটেন্ট (১২২টি প্রশ্ন, ১০টি ব্লগ, ২টি ক্যারিয়ার লেখা, ৩২টি গ্লসারি শব্দ, ৭টি এক্সেল টেমপ্লেট)
কোডের ভেতরেই আছে; অ্যাডমিন প্যানেল থেকে এক ক্লিকে যোগ হবে (ধাপ ৮)।

## ২. GitHub-এ কোড রাখুন 🖱️

1. <https://github.com> এ ফ্রি অ্যাকাউন্ট খুলুন।
2. ওপরে ডানে **+** → **New repository**।
   - নাম: `procurebest`
   - **Private** বেছে নিন (কোড অন্য কেউ দেখবে না)
   - **Create repository** চাপুন।
3. নতুন repository পাতায় **uploading an existing file** লিংকে ক্লিক করুন।
4. ZIP খুলে `procurebest-cf` ফোল্ডারের **ভেতরের সবকিছু** (src, public, docs, dev, wrangler.jsonc, package.json …) টেনে এনে ছেড়ে দিন।
   ফোল্ডারটি নিজে নয়, ভেতরের জিনিসগুলো — যাতে `wrangler.jsonc` সবার ওপরের স্তরে থাকে।
5. নিচে **Commit changes** চাপুন।

> ⚠️ `.gitignore` ফাইলটি লুকানো থাকতে পারে; না উঠলেও সমস্যা নেই।

## ৩. Cloudflare অ্যাকাউন্ট 🖱️

<https://dash.cloudflare.com/sign-up> এ ফ্রি অ্যাকাউন্ট খুলুন। কার্ড লাগবে না।

---

## ৪. ডাটাবেস (D1) তৈরি করুন 🖱️

1. বাঁ মেনুতে **Storage & Databases → D1 SQL Database → Create** (নাম একটু ভিন্ন হতে পারে)।
2. নাম দিন `procurebest` → **Create**।
3. তৈরি হলে পাতায় **Database ID** দেখাবে (লম্বা কোড, যেমন `3f2a…-…`)। কপি করে কোথাও রাখুন।

টেবিল নিজে বানাতে হবে না — সাইট প্রথমবার চালু হলে নিজেই সব তৈরি করে নেবে।

---

## ৫. ফাইল স্টোরেজ (KV) তৈরি করুন 🖱️

বই, এক্সেল, সিভি ও ডক ফাইল এখানে থাকবে (ফ্রি প্ল্যানে মোট ১ GB, প্রতিটি ফাইল ~৯৫ MB পর্যন্ত, কার্ড লাগে না)।

1. **Storage & Databases → Workers KV → Create** (বা *Create a namespace*)।
2. নাম দিন `procurebest-files` → তৈরি করুন।
3. তালিকায় এর **ID** কপি করুন।

### আইডি দুটি বসান ✏️
1. GitHub-এ repository খুলে `wrangler.jsonc` ফাইলে ক্লিক করুন → ডানে পেনসিল (✏️ Edit) আইকন।
2. `PASTE-YOUR-D1-DATABASE-ID-HERE` মুছে D1-এর আইডি বসান।
3. `PASTE-YOUR-KV-NAMESPACE-ID-HERE` মুছে KV-এর আইডি বসান।
4. **Commit changes** চাপুন।

> KV না বানাতে চাইলে `wrangler.jsonc` থেকে পুরো `"kv_namespaces": [ … ],` অংশটি মুছে দিন। তখন ফাইল ডাটাবেসে থাকবে, কিন্তু প্রতিটি **৫ MB**-এর বেশি হতে পারবে না।

---

## ৬. সাইট চালু (Deploy) করুন 🖱️

1. Cloudflare-এ **Workers & Pages → Create → Import a repository** (বা *Connect to Git*)।
2. GitHub অ্যাকাউন্ট যুক্ত করুন, `procurebest` repository বেছে নিন।
3. Build সেটিংস যেমন আছে রাখুন (Deploy command: `npx wrangler deploy`)। **Deploy** চাপুন।
4. এক-দুই মিনিট পর সাইটের ঠিকানা দেখাবে, যেমন `https://procurebest.আপনার-নাম.workers.dev`।
   খুলে দেখুন — হোমপেজ আসা উচিত। `…/healthz` খুললে `{"ok":true}` দেখাবে।

এরপর থেকে GitHub-এ যেকোনো ফাইল বদলালে Cloudflare নিজে থেকে আবার চালু করবে।

---

## ৭. অ্যাডমিন পাসওয়ার্ড দিন 🖱️ ✏️

1. Cloudflare-এ আপনার Worker (`procurebest`) খুলুন → **Settings → Variables and Secrets → Add**।
2. Type: **Secret**, Name: `ADMIN_PASSWORD`, Value: কমপক্ষে ১২ অক্ষরের একটি শক্ত পাসওয়ার্ড → **Deploy / Save**।
3. ঠিকানার শেষে `/admin` লিখে খুলুন (যেমন `https://procurebest.আপনার-নাম.workers.dev/admin`) এবং পাসওয়ার্ড দিয়ে ঢুকুন।

> পাসওয়ার্ড কাউকে দেবেন না। পার্টনারদের সঙ্গে শেয়ার করলে নিয়মিত বদলান।
> পরপর ৮বার ভুল দিলে ১৫ মিনিট লগইন বন্ধ থাকবে।

## ৮. প্রাথমিক কনটেন্ট ও সেটিংস 🖱️

1. অ্যাডমিন ড্যাশবোর্ডে **প্রাথমিক কনটেন্ট যোগ করুন** বাটন চাপুন। কিছুক্ষণ পর পাতা আবার লোড হবে।
2. **সেটিংস** খুলে পূরণ করুন:
   - **পেমেন্ট:** আপনার bKash ও/বা Nagad নম্বর, অ্যাকাউন্টের ধরন (Personal/Merchant/Agent)।
   - **WhatsApp:** গ্রুপের ইনভাইট লিংক (ফোনে: Group info → Invite via link → Copy link)।
   - **যোগাযোগ:** ইমেইল/ফোন/ঠিকানা (যোগাযোগ পাতায় দেখাবে)।
   - **নতুন অর্ডার ও বার্তার খবর পাঠান এই ঠিকানায়:** আপনার ইমেইল (ইমেইল সেবা চালু হলে কাজ করবে)।
3. **পরীক্ষা** পাতায় দাম, সময়, পাস নম্বর দেখে নিন। এখন: প্রাথমিক ও অভিজ্ঞ ফ্রি (দিনে ২বার), বিশেষজ্ঞ ৳৫০০ (এক পেমেন্টে ৩বার)।

## ৯. ইমেইল যাচাই চালু করা (ঐচ্ছিক, পরে করলেও চলবে)

ইমেইল সেবা না থাকলে সাইট **"শুধু সংগ্রহ" মোডে** চলে: ভিজিটরের ইমেইল জমা হয়, কিন্তু যাচাই হয় না
(ভুয়া ইমেইল দিয়েও ডাউনলোড করা যায়)। পরীক্ষার সময় এটাই সুবিধাজনক। চালু করতে:

1. <https://www.brevo.com> এ ফ্রি অ্যাকাউন্ট খুলুন।
2. **Senders, Domains & Dedicated IPs → Senders** এ যে ঠিকানা থেকে ইমেইল যাবে সেটি যোগ ও যাচাই করুন।
   ডোমেইন কেনার আগে Gmail ঠিকানা দিলেও চলে, তবে ইমেইল **স্প্যামে** যেতে পারে। ডোমেইন কিনলে ধাপ ১২ দেখুন।
3. **SMTP & API → API Keys → Generate a new API key** → কপি করুন।
4. Cloudflare → Worker → **Settings → Variables and Secrets → Add** → Secret, Name: `BREVO_API_KEY`, Value: কপি করা কী।
5. অ্যাডমিন → সেটিংস → **যে ঠিকানা থেকে ইমেইল যাবে** ঘরে Brevo-তে যাচাই করা ঠিকানা লিখে সেভ করুন।
6. সেটিংসের নিচে **টেস্ট ইমেইল পাঠান** দিয়ে পরীক্ষা করুন।

চালু হলে ভিজিটর ইমেইল দিলে একটি লিংক পাবেন; লিংকে ক্লিক করে "নিশ্চিত করুন" চাপলেই কাজ এগোবে।
একই ব্রাউজারে আর কখনো ইমেইল লাগবে না।

## ১০. সব ঠিক আছে কিনা যাচাই (চেকলিস্ট)

| কী দেখবেন | কীভাবে |
|---|---|
| ক্যালকুলেটর | তিনটি ক্যালকুলেটরে **Load fictional example** চাপুন — ইংরেজি ও বাংলা দুটোতেই |
| এক্সেল/পিডিএফ | ফলাফলের নিচে **Download Excel** → ইমেইল দিন → ফাইল খুলুন। **Download PDF** → প্রিন্ট উইন্ডোতে "Save as PDF" |
| লাইব্রেরি | একটি ফ্রি ফাইল ডাউনলোড করুন |
| পেইড ফাইল | "Procurement KPI Dashboard" কিনুন (ছোট অঙ্ক পাঠিয়ে বা টেস্ট TrxID দিয়ে) → অ্যাডমিন → অর্ডার → অনুমোদন → ডাউনলোড হয় কিনা দেখুন |
| পরীক্ষা | প্রাথমিক পরীক্ষা দিন → পাস করলে সার্টিফিকেট → **প্রিন্ট / পিডিএফ সেভ** → মোবাইলে QR স্ক্যান করুন |
| পেইড পরীক্ষা | বিশেষজ্ঞ পরীক্ষা কিনে অনুমোদন দিন → "৩বার দেওয়া যাবে" দেখায় কিনা |
| WhatsApp | ক্যালকুলেটরের ফলাফলের নিচে সবুজ বাটন আপনার গ্রুপ খোলে কিনা |
| অ্যাডমিন | ইমেইল তালিকা → **CSV ডাউনলোড** এক্সেলে খোলে কিনা |

পরীক্ষার পর টেস্টের অর্ডার "বাতিল" করে দিতে পারেন, আর টেস্ট সার্টিফিকেট অ্যাডমিন → সার্টিফিকেট থেকে বাতিল করতে পারেন।

## ১১. প্রতিদিনের কাজ (অ্যাডমিন প্যানেল)

| কাজ | কোথায় |
|---|---|
| **পেমেন্ট অনুমোদন** | অর্ডার → bKash/Nagad অ্যাপে একই TrxID, নম্বর ও অঙ্ক মিলিয়ে **অনুমোদন**। না মিললে কারণ লিখে **বাতিল** |
| বই / এক্সেল / সিভি / ডক যোগ | লাইব্রেরি → আইটেম যোগ করুন → ধরন, শিরোনাম, দাম (০ = ফ্রি), ফাইল আপলোড → প্রকাশিত → সেভ |
| ব্লগ বা ক্যারিয়ার লেখা | ব্লগ / ক্যারিয়ার → নতুন লেখা (Markdown: `## শিরোনাম`, `- তালিকা`, `**মোটা**`) |
| গ্লসারি | গ্লসারি → নতুন শব্দ |
| প্রশ্ন বানানো/বদলানো | প্রশ্নব্যাংক → নতুন প্রশ্ন, অথবা CSV এক্সপোর্ট করে এক্সেলে এডিট → "CSV UTF-8" হিসেবে সেভ → ইমপোর্ট (একবারে ৩০০টি পর্যন্ত) |
| পরীক্ষার দাম/সময় | পরীক্ষা |
| ইমেইল তালিকা | ইমেইল তালিকা → ফিল্টার (যাচাইকৃত / নিউজলেটার / ক্রেতা) → CSV ডাউনলোড |
| কে কী ডাউনলোড করল | ডাউনলোড ও কার্যক্রম |
| সার্টিফিকেট বাতিল | সার্টিফিকেট → কারণ লিখে বাতিল (যাচাই পাতায় "বাতিল" দেখাবে) |
| হোমপেজের লেখা | সেটিংস → হোমপেজ ও সাইটের লেখা |

> **ফাইলের আকার:** KV থাকলে প্রতিটি ফাইল ~৯৫ MB পর্যন্ত (মোট ১ GB)। বড় পিডিএফ বই আগে কম্প্রেস করে নিলে ভিজিটরদের ডাউনলোডও দ্রুত হবে।
> অ্যাডমিন ভাষা: ওপরের EN / বাংলা সুইচ।

## ১২. পরে ডোমেইন যুক্ত করা (procurebest.com)

1. Cloudflare → **Domain Registration → Register Domains** থেকে ডোমেইন কিনুন (বার্ষিক ফি দিতে হয়)।
2. Worker → **Settings → Domains & Routes → Add → Custom domain** → `procurebest.com` (চাইলে `www.procurebest.com`-ও)।
3. কয়েক মিনিটে HTTPS সহ চালু হবে। পুরনো `workers.dev` ঠিকানাও কাজ করবে।
4. ইমেইল স্প্যামে না যাওয়ার জন্য: Brevo → **Domains** → procurebest.com যোগ করুন → Brevo যে DNS রেকর্ড (SPF/DKIM/DMARC) দেখায় সেগুলো Cloudflare → DNS-এ যোগ করুন → অ্যাডমিন সেটিংসে প্রেরক `no-reply@procurebest.com` দিন।
5. (ঐচ্ছিক) Worker → Settings → Variables-এ `SITE_URL` = `https://procurebest.com` দিন, যাতে ইমেইল ও QR কোডের লিংক সবসময় মূল ডোমেইন দেখায়।

## ১৩. ব্যাকআপ

- অ্যাডমিন থেকে নিয়মিত **ইমেইল তালিকা** ও **প্রশ্নব্যাংক** CSV ডাউনলোড করে নিরাপদ জায়গায় রাখুন।
- আপলোড করা বই/ফাইলের মূল কপি নিজের কম্পিউটার বা ড্রাইভে রাখুন।
- Cloudflare D1 কিছুদিনের পুরনো অবস্থায় ডাটাবেস ফেরানোর সুবিধা (Time Travel) দেয়; বিস্তারিত Cloudflare-এর D1 ডকুমেন্টেশনে।
- কোড GitHub-এ থাকে, তাই কোডের ব্যাকআপ আলাদা লাগে না।

## ১৪. ফ্রি প্ল্যানের সীমা (সংক্ষেপে)

| জিনিস | ফ্রি সীমা | আপনার জন্য |
|---|---|---|
| পাতা দেখা (Worker রিকোয়েস্ট) | দিনে ১,০০,০০০ | শুরুতে যথেষ্ট |
| CSS/ছবি/ক্যালকুলেটরের ফাইল | সীমাহীন | — |

| ফাইল (KV) | মোট ১ GB, দিনে ১,০০০ আপলোড-অংশ | কয়েকশো ফাইল |
| ইমেইল (Brevo ফ্রি) | দিনে সীমিত সংখ্যক | শুরুতে যথেষ্ট; বাড়লে পেইড প্ল্যান |

সর্বশেষ সীমা Cloudflare ও Brevo-র নিজস্ব পাতায় দেখে নিন।

| সমস্যা | সমাধান |

| Deploy ব্যর্থ, লেখা "database_id" বা "kv" | `wrangler.jsonc`-এ আইডি ঠিকমতো বসেছে কিনা দেখুন (উদ্ধৃতিচিহ্নের ভেতরে) |

| ভিজিটর বলছে ডাউনলোড লিংক কাজ করছে না | লিংক ১০ মিনিট বৈধ — পাতায় গিয়ে আবার ডাউনলোড চাপতে বলুন |
| WhatsApp বাটন দেখা যায় না | সেটিংসে লিংক `https://chat.whatsapp.com/…` আকারে আছে কিনা |
| Worker-এর ত্রুটি দেখতে চান | Cloudflare → Worker → **Logs / Observability** |
